# ADR 0001: 独立项目与数据边界

- 状态：Accepted
- 日期：2026-08-26

## 决策

AI Chat Hub 使用独立代码目录、Git 仓库、配置、数据库和运行环境。它不读取、修改或迁移 AI Council 的任何资产，也不复用其角色、路由和 Consensus。

Open WebUI 只能作为界面设计参考；若未来派生，必须先完成许可证、升级成本和数据隔离评估，并在本仓库中形成全新的配置与数据库。默认接入方式是用户本机的官方网页订阅，不是模型 API。

浏览器登录信息与 Cookie 留在项目目录之外的 Mac 本地浏览器上下文。应用数据库只存回复原文、来源、状态和用户自建元数据，不存认证材料。

## 后果

- 初期开发量高于直接修改 AI Council 或复用现有 Open WebUI 实例。
- 项目可以独立升级、回滚和删除，不影响现有系统。
- 每个平台适配器都必须承担页面变化、条款和安全失败处理成本。
