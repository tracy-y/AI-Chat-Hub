# ADR 0002: 本地运行与公开分发模式

- 状态：Accepted
- 日期：2026-08-26

## 背景

AI Chat Hub 首先供开发者本人在 Mac 本地使用，成熟后计划通过公开 GitHub 仓库供其他人下载。产品希望优先复用用户已经购买的官方 AI 网页订阅，而不是要求用户再次为默认 API 接入付费。

## 决策

1. 应用在每位用户自己的电脑上运行，不提供中心化 AI 代理服务。
2. 每位用户自行在官方平台完成注册、登录、订阅和账号管理。
3. 登录凭据、浏览器 Session 和 Cookie 不上传到项目维护者或任何项目服务器。
4. GitHub 仓库只包含代码、公开文档、匿名 fixture 和构建配置。
5. 仓库不得包含开发者或用户的浏览器 Profile、Cookie、聊天数据库、导出记录或私人测试样本。
6. 项目不共享、转售、代管或集中轮换任何官方 AI 账号与订阅。
7. 每个真实平台适配器必须单独通过当前条款、权限和技术可维护性审查后才可启用。

## PoC 技术方向

优先验证浏览器扩展侧边栏：它可在用户可见的浏览器环境中工作，并复用用户自己完成的官方登录。平台无关核心、Mock Adapter 与本地存储可以先行开发；真实站点交互不得在 P0 审查前默认启用。

## 后果

- 项目不承担用户订阅费用，也不能保证各官方平台持续兼容。
- 网页变化可能要求频繁更新适配器，并在不安全时自动停用。
- 公开发布前必须选择开源许可证，并审查依赖、商标、平台名称和分发文案。
- 用户必须理解 AI Chat Hub 不是各 AI 平台的官方客户端或授权代理。
