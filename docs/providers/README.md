# Provider assessments

Real provider adapters are disabled until their assessment reaches `Go`.

| Provider | Subscription web automation | Assisted manual relay | API adapter |
|---|---|---|---|
| ChatGPT | Unconfirmed | Candidate | Optional, separate product |
| Claude | Stop without explicit permission | Candidate | Optional, separately billed |

Assessments contain no account identifiers, cookies, tokens, screenshots, or private conversations. They record only public sources and implementation conclusions.
